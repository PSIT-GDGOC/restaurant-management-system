# Restaurant Management System

A full-stack web application starter for restaurant management.

## Tech Stack

- Frontend: React + Vite
- Backend: Java + Spring Boot
- Build Tool: Maven

## Project Structure

```text
restaurant-management-system/
├── frontend/
├── backend/
├── README.md
└── LICENSE
```

## Prerequisites

- Node.js and npm
- Java Development Kit (JDK)

## Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Run the Backend

Open a separate terminal:

```bash
cd backend
```

Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

The backend runs on port 8080.

## Health Check

Open http://localhost:8080/api/health to verify that the backend is running.

## Project Status

This repository currently contains the initial frontend and backend boilerplate. Restaurant management features will be added in future development.
